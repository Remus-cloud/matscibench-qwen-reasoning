# DSC6020 · 基于 Qwen3.5-27B 的材料科学推理

我们以 Qwen3.5-27B 为基础，研究不同答题策略能否提高模型解答材料科学数值题的正确率。我们从 MatSciBench 选取无需图像、具有单一数值答案的题目，固定 20 道开发题和 120 道测试题。在开发集上确定提示、计算器触发条件和投票规则，再用同一模型回答全部测试题。[MatSciBench 数据集](https://huggingface.co/datasets/JunkaiZ/MatSciBench)

## 正式测试结果

| 答题方法 | 正确题数 | 准确率 | 已记录的总 token |
|---|---:|---:|---:|
| 直接回答 | 32/120 | 26.7% | 24,494 |
| 普通 CoT | 94/120 | 78.3% | 210,973 |
| CoT + 条件计算器 | 95/120 | 79.2% | 324,563* |
| CoT + Self-Consistency（5 票） | 93/120 | 77.5% | 1,140,585 |

\* 计算器组第 85 题缺少用量回执，该组 token 合计覆盖 119 题。四组准确率均按全部 120 题计算。

要求模型写出公式、代入数值并展示计算过程后，普通 CoT 比直接回答多答对了 **62 题**。条件计算器组比普通 CoT 多答对 1 题，但两组答案出现分歧的 15 道题都没有实际调用计算器，因此无法把这 1 题的净增归因于工具。五票组以温度 0.6 独立作答五次，用约 5.4 倍于普通 CoT 的 token 得到 93/120，比普通 CoT 少答对 1 题。[逐题结果](results/questions.jsonl) · [实验设计与评分规则](docs/EXPERIMENTS.md)

## 演示与复现

在浏览器中打开课堂演示，可以逐题查看四组回答、计算器记录和五票结果。第 72 题展示了模型如何用计算器复核氯化铯的缺陷浓度。[离线演示](demo/index.html)

## QLoRA 微调

我们从同一基准的其他题目中筛选了 120 道监督训练题和 26 道内部验证题，并按教材母题、题干近重复和解题家族筛查与开发集、测试集的重叠。我们在 Qwen3.5-27B 的语言层上训练 LoRA 适配器，使用 4-bit NF4、rank 8、alpha 16 和学习率 3e-5，训练 1 个 epoch，共 30 次参数更新。[底座模型](https://huggingface.co/Qwen/Qwen3.5-27B) · [checkpoint-30 适配器](models/v3-checkpoint-30/)

微调权重已包含在本仓库中，微调模型在完整 120 道测试题上的评测结果尚未获得。
